# YouTalk Blog

Учебный проект по адаптивной вёрстке сайта YouTalk по макету Figma.

В проекте реализованы две страницы:

* `index.html` — страница блога;
* `article.html` — страница статьи.

---

## Описание проекта

Проект выполнен в рамках практической работы по фронтенд-разработке.

Основная цель работы — сверстать адаптивный сайт по макету, закрепить навыки работы с HTML, CSS, семантической разметкой, Flexbox, CSS Grid, медиа-запросами и методологией БЭМ.

---

## Технологии

* HTML5;
* CSS3;
* Flexbox;
* CSS Grid;
* Media Queries;
* БЭМ.

## Особенности реализации

* Использована семантическая HTML-разметка: `header`, `main`, `footer`, `nav`, `section`, `article`, `aside`.
* Классы названы по методологии БЭМ.
* Добавлены псевдоэлементы и псевдоклассы.
* У изображений прописаны атрибуты `alt`.
* Декоративные изображения скрыты от скринридеров с помощью `aria-hidden="true"`.
* Иконки используются в формате SVG.
* Изображения вынесены в отдельную папку `images`.
* Вёрстка адаптирована под десктоп, планшет и мобильные устройства (1440,1024,768,414,320).

## Запуск проекта

Скачайте проект и откройте файл `index.html` в браузере.

Для просмотра страницы статьи откройте файл `article.html`.
